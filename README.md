# LeagueLedger

## Cloud Native Football League Management Platform

LeagueLedger is a football competition management platform built with modern software engineering practices.

## Technology Stack

- FastAPI
- React
- PostgreSQL
- Docker
- Kubernetes
- GitHub Actions

## Deployment

### Docker Compose

```bash
docker compose up --build
```

### Kubernetes

```bash
kubectl apply -f k8s/
```

## Architecture

Application API and database are deployed as containerized services with Kubernetes orchestration.

## Roadmap

Future versions may include analytics and AI-assisted sports intelligence capabilities.
